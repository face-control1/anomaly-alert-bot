# AnomalyAlert — Telegram-бот для отслеживания аномалий на бирже

Бот мониторит **Московскую биржу (MOEX)** и **СПБ Биржу** и мгновенно присылает
алерты об аномальных событиях подписчикам.

---

## Возможности

| Функция | Описание |
|---|---|
| Аномальный объём | Объём торгов в 3x и более выше скользящего среднего |
| Резкое движение цены | Изменение цены >3% за 1 минуту |
| Полосы Боллинджера | Пробой 2.5σ от 20-периодной скользящей средней |
| Персональные тикеры | Добавьте свои инструменты для отслеживания |
| Платная подписка | 250 Stars Telegram / месяц |
| Пробный период | 24 часа бесплатно |

---

## Быстрый старт

### 1. Создайте бота

Напишите @BotFather в Telegram:
```
/newbot
/mybots -> Payments -> Connect provider -> Stars
```

### 2. Установите зависимости

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройте конфигурацию

```bash
cp .env.example .env
nano .env   # вставьте BOT_TOKEN и ADMIN_IDS
```

### 4. Запустите

```bash
python main.py
```

## Платёжная система — Telegram Stars

Оплата реализована через **Telegram Stars** (встроенная валюта Telegram).

- Никакого внешнего эквайринга, кошельков, webhook-ов от платёжек
- Работает во всех странах, где есть Telegram
- Возвраты обрабатываются автоматически (refunded_payment)
- Вывод Stars через Fragment (после 1000 Stars, через 21 день)

| Параметр | Значение |
|---|---|
| Цена | 250 Stars ≈ $3.25/мес |
| Пробный период | 24 часа |
| Длительность подписки | 30 дней |

## Deploy на Render.com (бесплатно)

1. Форкните/создайте репозиторий с этим кодом на GitHub
2. Зарегистрируйтесь на render.com
3. New → Web Service → подключите GitHub репозиторий
4. Добавьте переменные окружения: `BOT_TOKEN`, `ADMIN_IDS`
5. Render автоматически обнаружит `render.yaml` и запустит бота
6. Настройте UptimeRobot (бесплатно) для пинга каждые 5 минут

## API источники данных

- **MOEX ISS**: бесплатный публичный API https://iss.moex.com/iss
- Данные: котировки, свечи, справочник инструментов
- Лимиты: ~1 запрос/сек (бот делает паузы 300мс между запросами)
